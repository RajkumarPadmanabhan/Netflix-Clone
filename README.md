# 🎬 Netflix Clone – Full Stack Web Application

## 📌 Project Summary

Developed a Netflix-inspired movie streaming platform that enables users to discover, browse, and stream movies, TV shows, and documentaries through a modern and responsive interface. The application provides secure authentication, separate user experiences for kids and adults, and seamless video playback. Built using full-stack web technologies, the platform efficiently manages user data and streaming content while delivering an engaging viewing experience.

## 🚀 Key Features

✅ User Registration & Login Authentication
✅ Separate Profiles for Kids and Adults
✅ Browse Movies, TV Shows & Documentaries
✅ Search and Discover Content Easily
✅ Integrated Video Streaming Player
✅ Responsive Design for Desktop and Mobile Devices
✅ Dynamic Content Management
✅ Secure User Session Management
